# كورس تطبيق الضوابط الأساسية للأمن السيبراني ECC-2:2024: النسخة المصححة

النسخة المصححة من العرض التدريبي (الإصدار 39، 174 شريحة)، بعد مراجعته مقابل الوثائق الرسمية للهيئة الوطنية للأمن السيبراني، مع مسار تطبيقي للمبتدئين واختبار أداء.

## المحتويات

| المجلد | ما فيه |
|---|---|
| `01_العرض_المصحح/` | ملف PowerPoint قابل للتحرير (187 شريحة، ولكل شريحة ملاحظات مدرب)، ونسخة PDF للمعاينة (تحويل LibreOffice للملف نفسه)، ونسخة PDF مرجعية للتصميم من المتصفح |
| `02_النسخة_الأصلية_v39/` | الإصدار 39 دون تعديل في المحتوى، محولاً إلى PowerPoint وPDF بالأداة نفسها، للمقارنة |
| `03_ملفات_المتدرب/` | ملف الجهة الافتراضية «هيئة المدار للخدمات الرقمية»، والتطبيقات الثلاثة (2-2، 2-9، 4-1): حالة التطبيق وملف البيانات والقالب الفارغ؛ وأدلة اختبار الأداء وورقة الإجابة؛ وأسئلة الاختبار المعرفي؛ و«كراسة التمارين التطبيقية» (12 تمريناً بسيناريوهات ومستندات وأوراق إجابة) في `06_كراسة_التمارين/` |
| `04_ملفات_المدرب_فقط/` | دليل المرفقات، والحلول ومعايير التصحيح للتطبيقات الثلاثة، ومفتاح اختبار الأداء، ومفتاح الاختبار المعرفي، و«دليل المدرب: شرح التمارين والحلول» للكراسة. لا يُشارك مع المتدربين |
| `05_التقارير/` | سجل التغييرات (كل شريحة أصلية ورقمها الجديد وتعديلها)، وسجل المصادر وتاريخ التحقق، وقائمة المعلومات التي لم يتم التحقق منها والافتراضات التدريبية والفحوص التي لم تُنفذ، وتقرير فحص التحويل |
| `06_الخطوط/` | خطوط Alexandria وIBM Plex Sans Arabic وIBM Plex Mono (رخصة OFL). ثبّتها قبل فتح ملف العرض |
| `source/` | مصدر العرض بصيغة HTML والبرامج التي ولّدت العرض والمرفقات والتقارير، كما استُخدمت في مجلد العمل؛ مساراتها مبنية على ذلك المجلد |

## قبل الاستخدام

- ثبّت الخطوط من `06_الخطوط/`، وإلا استبدلها PowerPoint بخطوط أخرى وتغيرت فواصل الأسطر.
- الفحص البصري تم على تحويل LibreOffice وعلى مرجع المتصفح، لا في Microsoft PowerPoint نفسه.
- جميع الأسماء والأرقام في نماذج الأدلة والتطبيقات واختبار الأداء افتراضية لأغراض التدريب.
- عمود «المطلوب» في جداول الضوابط يعيد صياغة النص الرسمي؛ عمودا «كيف تطبقه» و«الدليل» ممارسات مقترحة وليست متطلبات من الهيئة. النص العربي الرسمي هو المعتمد عند أي اختلاف.
